# Portfolio Resume

A modern, interactive portfolio and resume website for Justine G. Odi, showcasing Computer Science skills and projects.

## Features

- **Responsive Design**: Optimized for desktop and mobile viewing
- **Dynamic GitHub Integration**: Automatically fetches and displays GitHub repositories
- **Dark Theme**: Sleek code editor-inspired dark interface with custom color scheme
- **Clean Layout**: Professional two-column layout with sidebar for quick contact and skills information
- **Interactive Elements**: Real-time age calculation and repository status updates

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS variables for theming
- **APIs**: GitHub REST API for dynamic repository fetching

## Getting Started

1. Clone this repository
2. Open `index.html` in a web browser
3. Customize the content with your own information

## Customization

### Update Personal Information

Edit `index.html` to update:
- Name and contact information
- Technical skills and tools
- Education and experience
- Project details

### Modify Theme

Adjust colors in `style.css` by editing the CSS variables:
```css
:root {
  --paper: #0c0f12;
  --panel: #11161b;
  --ink: #e6edf3;
  /* ... more colors ... */
}
```

### Update GitHub Username

Change the GitHub username in `script.js` to display your own repositories.
